# luka00 portfolio

Open index.html to view the site. No installation or build step is required. For local hosting, run `python3 -m http.server 8000` inside this folder and visit http://localhost:8000.

Upload the contents of this folder to GitHub Pages or any static host. The original page names remain available. Each photo story now has its own HTML page.

Edit HTML files for copy, credits, links and project order. Shared styles and gallery interactions are in assets/. Original photographs are preserved in images/; responsive WebP copies are in images/web/. Gallery photographs open a keyboard-accessible viewer (arrow keys and Escape). Without JavaScript they link to the originals. The video needs an internet connection.

Original project credits, contact details, biography and video were retained. The referenced conversation did not expose the generated mockup images; this implementation follows the approved written design direction.

## Languages
The EN / SL header button switches all interface and descriptive text between English and Slovene, and remembers the choice in browser storage. Project and artist names stay unchanged. Translations are in assets/language.js. JavaScript must be enabled for language switching.
